# References

First Dollar is an independent, evolving field guide. External sources inform it, but no source is treated as permanently authoritative. Changes should distinguish the source principle, the First Dollar adaptation, and evidence from real use.

## Primary foundation

### The Minimalist Entrepreneur — Sahil Lavingia

Current role: primary foundation for First Dollar v0.1.

Principles currently retained:

- Stay close to a reachable community and its problems.
- Sell and learn before scaling.
- Deliver value manually before making large product investments.
- Charge early enough to test willingness to pay.
- Prefer profitability, autonomy, and sustainable growth.
- Build a company the founder wants to operate.

First Dollar adaptations:

- Select the cheapest credible experiment instead of requiring manual delivery in every case. An AI-assisted prototype is appropriate when it produces credible learning faster and more cheaply.
- Treat AI-generated output, deployed prototypes, traffic, and attention as supply or interest evidence—not demand evidence.
- Define the first-dollar milestone as a settled, non-test, non-circular customer payment for a specific offer.
- Treat payment and promised delivery as one ethical and operational learning loop.
- Keep interpretation, customer promises, consequential decisions, and external actions human-owned.

Open questions to test through practice:

- Must a founder begin inside an existing community, or is a precisely reachable buyer segment sufficient?
- When is an AI-assisted prototype cheaper and more informative than manual delivery?
- Which forms of buyer commitment predict payment and repeat use?
- When should a repeated AI-assisted service become software?
