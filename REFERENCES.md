# References

The Agent Bootstrapper is an independent, evolving field guide. External sources inform it, but no source is treated as permanently authoritative. Changes should distinguish the source principle, the Agent Bootstrapper adaptation, and evidence from real use.

## Primary foundation

### The Minimalist Entrepreneur — Sahil Lavingia

Current role: primary foundation for The Agent Bootstrapper v0.1.

Principles currently retained:

- Stay close to a reachable community and its problems.
- Sell and learn before scaling.
- Define a credible delivery process before making large product investments.
- Charge early enough to test willingness to pay.
- Prefer profitability, autonomy, and sustainable growth.
- Build a company the founder wants to operate.

Agent Bootstrapper adaptations:

- Treat agents as infrastructure for reversible research, drafting, prototyping, transformation, and supervised operation.
- Select the cheapest credible experiment instead of requiring manual delivery in every case. An agent-built prototype is appropriate when it can safely test the important assumption in hours.
- Treat generated output, deployed prototypes, traffic, and attention as supply or interest evidence—not demand evidence.
- Define the first-dollar milestone as a settled, non-test, non-circular customer payment for a specific offer.
- Treat payment and promised delivery as one ethical and operational learning loop.
- Keep interpretation, customer promises, consequential decisions, and external actions human-owned.

Open questions to test through practice:

- Must a founder begin inside an existing community, or is a precisely reachable buyer segment sufficient?
- When is an agent-built prototype cheaper and more informative than research or manual delivery?
- Which forms of buyer commitment predict payment and repeat use?
- When should a repeated agent-assisted service become durable software?

## Adding future references

For each new source, record:

- the claim or practice being considered;
- where it applies and where it may fail;
- whether The Agent Bootstrapper retains, adapts, rejects, or is still testing it;
- what field evidence would change the decision.
